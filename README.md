# Proyecto 3 – Clustering y reducción de dimensión (Sleep Health and Lifestyle)

Curso de Machine Learning · Universidad de Medellín

- **Dataset:** [Sleep Health and Lifestyle](https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset) (clasificación multiclase de `Sleep Disorder`: None / Insomnia / Sleep Apnea)
- **Parte 1:** descripción, EDA, K-means, clustering jerárquico aglomerativo y DBSCAN (comparados contra las clases reales)
- **Parte 2:** selección de características SFFS (wrapper) + PCA + LDA, con MLP como clasificador

## Ejecución
1. Descargar el CSV de Kaggle y guardarlo como `Sleep_health_and_lifestyle_dataset.csv` junto al notebook (o dejar que `kagglehub` lo descargue).
2. `pip install -r requirements.txt`
3. Abrir `Proyecto3_Sleep_Health.ipynb` y ejecutar todo (en Colab, descomentar la celda de `pip install`).
